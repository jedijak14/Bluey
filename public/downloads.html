One important distinction.

Closing Kids does not stop an installed Guardian service. But the app window is not an OS security barrier. Guardian currently targets a standard Windows child account with Edge and Chrome URL policies. No all-browser filter, Android OS filtering, or non-bypassable login lock is included.

Older Guardian enrollments stay Edge-only until parent recovery and re-enrollment. Missing Guardian shows “Admin Permissions is needed” in Kids desktop. Granting permission to install the companion alone does not enable protection. General Kids AI chat is not implemented.

A parent sets things up.

On the child’s Windows test PC, open the Home Windows app and choose Install or recover Windows Guardian. Approve the Windows administrator prompt and follow the local wizard. New enrollment needs a working family backend; administrator recovery works offline. This does not grant permissions from the website or Android app.

Windows downloads are x64 and unsigned. APKs are Android debug previews; a changed signing key may require uninstalling an earlier APK, clearing its local data. Do not disable existing safety controls to install Bluey.
